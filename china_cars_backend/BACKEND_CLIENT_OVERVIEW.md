# Бэкенд Primcom: описание для заказчика

Дата актуализации: 2026-02-24

Этот файл описывает возможности backend-продукта простым деловым языком.
Файл обновляется после ключевых изменений в API, парсере, ботах и логике данных.

## Что умеет backend сейчас

### 1. Каталог авто из Китая

- Автоматически собирает карточки из внешних источников (guazi, che168, dongchedi).
- В рабочем контуре на сервере основной источник сейчас `guazi`.
- Для каждой карточки сохраняет цену, пробег, год, характеристики, ссылку на источник и фото.
- Отдает данные на сайт через API: список, фильтры и детальную страницу карточки.

### 2. Ручные карточки Японии и Кореи

- Есть отдельный менеджер-бот в Telegram для ручного добавления карточек.
- Бот поддерживает создание, редактирование, удаление и просмотр последних карточек.
- Для японских карточек поддерживается поле "оценка по аукционному листу".
- Все операции менеджера защищены API-ключом.

### 3. Парсер и автоматическое обновление базы

- Парсер запускается по расписанию через systemd timer.
- Есть ручной запуск для ускоренного наполнения каталога.
- Поддерживается ограничение на количество новых карточек за запуск.
- Автоматическое удаление старых карточек после парсинга отключено по умолчанию (безопасный режим).

### 4. Работа с фото и качество карточек

- Фото скачиваются и хранятся локально на сервере.
- Для guazi добавлена фильтрация служебных картинок (QR, иконки, логотипы и т.д.).
- В публичную выдачу не попадают карточки без валидных изображений.
- Есть сервисный скрипт очистки пустых карточек.

### 5. Перевод и нормализация данных

- Китайские названия переводятся в процессе загрузки данных.
- Поддерживается перевод через proxy/OpenAI.
- Добавлены ретраи и увеличенные таймауты для стабильной работы при массовом парсинге.

### 6. API и эксплуатация

- Доступны служебные endpoint-ы для проверки состояния (`/health`) и контроля запусков скрейпера.
- Ведется журнал запусков и технические логи для диагностики.
- Есть отдельный endpoint для заявок с сайта (`/api/lead`).
