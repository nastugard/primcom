2. Основные понятия, используемые в Политике

2.1. Автоматизированная обработка персональных данных — обработка персональных данных с помощью средств вычислительной техники.

2.2. Блокирование персональных данных — временное прекращение обработки персональных данных (за исключением случаев, если обработка необходима для уточнения персональных данных).

2.3. Веб-сайт — совокупность графических и информационных материалов, а также программ для ЭВМ и баз данных, обеспечивающих их доступность в сети Интернет по адресу https://primcom.ru.

2.4. Информационная система персональных данных — совокупность содержащихся в базах данных персональных данных и обеспечивающих их обработку информационных технологий и технических средств.

2.5. Обезличивание персональных данных — действия, в результате которых невозможно определить принадлежность персональных данных конкретному Пользователю без использования дополнительной информации.

2.6. Обработка персональных данных — любое действие (операция) или совокупность действий с персональными данными, включая сбор, запись, систематизацию, накопление, хранение, уточнение, использование, передачу, блокирование, удаление, уничтожение.

2.7. Оператор — физическое лицо (индивидуальный предприниматель), самостоятельно организующее и осуществляющее обработку персональных данных.

2.8. Персональные данные — любая информация, относящаяся к прямо или косвенно определяемому Пользователю веб-сайта https://primcom.ru.

2.9. Пользователь — любой посетитель веб-сайта https://primcom.ru.

2.10. Предоставление персональных данных — действия, направленные на раскрытие персональных данных определённому лицу или кругу лиц.

2.11. Распространение персональных данных — любые действия, направленные на раскрытие персональных данных неопределённому кругу лиц.

2.12. Трансграничная передача персональных данных — передача персональных данных на территорию иностранного государства.

2.13. Уничтожение персональных данных — действия, в результате которых персональные данные уничтожаются безвозвратно.

3.2. Оператор обязан:

  • предоставлять Пользователю информацию об обработке его персональных данных;

  • отвечать на обращения и запросы субъектов персональных данных;

  • принимать правовые, организационные и технические меры защиты персональных данных;
  • прекращать обработку и уничтожать персональные данные в предусмотренных законом случаях.

4.1. Пользователь имеет право:

  • отзывать согласие на обработку персональных данных;

4.2. Пользователь обязан:

5. Принципы обработки персональных данных

5.1. Обработка осуществляется на законной и справедливой основе.

5.2. Обработка ограничивается достижением конкретных и законных целей.

5.3. Не допускается избыточная обработка персональных данных.

5.4. Обеспечивается точность и актуальность персональных данных.

5.5. Хранение персональных данных осуществляется не дольше, чем это требуется целями обработки.

6. Цели обработки персональных данных

Цели обработки:

  • информирование Пользователя;
  • обработка обращений и заявок;
  • предоставление консультаций и услуг;

Персональные данные:

  • адрес электронной почты;
  • номер телефона;

  • данные документов (при необходимости);
  • IP-адрес, cookies, данные об устройстве.

Правовые основания:

  • согласие субъекта персональных данных;
  • договоры, заключаемые между Оператором и Пользователем.
