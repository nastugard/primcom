# Предлагаемая структура

Существующие URL сохраняются. Новые адреса ниже — проектные, страницы ещё не созданы. Кластеры сформированы по намерению покупателя, без количественного расчёта пересечения SERP.

| Задача | Основной адрес | Решение |
|---|---|---|
| Авто из Японии / Кореи / Китая, под заказ, цены | `/pages/auto-iz-yaponii.html`, `/pages/auto-iz-korei.html`, `/pages/auto-iz-kitaya.html` | Улучшить существующие страницы; статично доступные полезные предложения и описание услуги, полный бюджет, проверка, доставка, CTA |
| Страна → марка → модель | `/cars/{country}/{make}/{model}/` | Сохранить и обогатить текущие страницы; кириллица и латиница на одной странице модели |
| Машина до 2 млн | `/cars/podborki/do-2-mln/` | Одна новая подборка разных стран; границы бюджета и город выдачи объяснены |
| До 160 л.с. | `/cars/podborki/do-160-ls/` | Одна новая подборка, страны — секции/фильтры. Отдельные страны позже при уникальном полезном наполнении |
| Семейный минивэн | `/cars/podborki/miniveny-iz-yaponii/` | Новая подборка только проверенных моделей |
| Расшифровка листа | `/guides/kak-chitat-aukcionnyy-list/` | Один подробный материал с реальным примером, редактором и датой проверки |
| Платежи при ввозе | `/pages/kalkulyator-stoimosti.html`, `/pages/rastamozhka-i-poshliny.html` | Разделить задачу расчёта и объяснение платежей; не создавать одинаковые страновые калькуляторы |
| Примеры привоза | `/cases/` и `/cases/{real-case}/` | Создавать только после получения материалов; связать с моделями и подборками |
| Доставка и гарантии | `/pages/dostavka.html`, `/pages/dogovor-i-garantii.html` | Доработать существующие страницы, не плодить дубли |

Входы на новые подборки: главный экран/навигация каталога, страницы стран, релевантные модели и руководства. Из подборки — ссылки на модели; из модели — альтернативы и подходящие подборки. Из информационного материала — релевантная модель/подборка и действие по проверке или расчёту.

Фильтры бюджета, страны, кузова и мощности не должны автоматически создавать бесконечные индексируемые комбинации. Для поиска отбирать редакционно полезные посадочные со стабильными URL и уникальными фактами. Один основной URL на одно намерение; не делать отдельные страницы на перестановки слов и синонимы.

Условия публикации подборки: несколько действительно подходящих предложений или полезное сравнение проверенных моделей, честный статус актуальности, объяснение критериев, понятный следующий шаг. Пустую подборку не публиковать ради ключевой фразы.
