- Первый браузерный расчёт завершился через 20 секунд таймаутом; пользовательский текст ошибки: signal is aborted without reason.
- Повторный браузерный расчёт выполнился за 0,705 сек, событие calculator_result_success отправлено. Параметры: 10000 USD, 2 л, 238 л.с., 3–5 лет, бензин, личное пользование, физлицо. Получено 3 223 038 ₽ автомобиля и обязательных платежей. Это функциональная проверка, а не подтверждение правовой/финансовой точности тарифов.
- Два отдельных запроса POST https://primcom.ru/api/import-calculator/calculate вернули HTTP 502 за 18,39 и 15,48 сек. Ответ хостинга: Failed to connect to api.primcom.ru port 443 after 15002 ms: Timeout was reached.
- Прямой POST https://api.primcom.ru/api/import-calculator/calculate оба раза вернул HTTP 200 приблизительно за 1,15 сек. GET /health — 200; CORS preflight OPTIONS — 200, Origin https://primcom.ru разрешён.
- Следовательно, неполная загрузка фронтенда не является причиной. Подтверждён отказ соединения хостинга с API в двух контрольных запросах; точная причина на стороне сети/прокси без серверной диагностики не установлена. Резервный прямой маршрут срабатывает, но первая попытка может быть медленной или неуспешной.

Нужно проверить соединение и проксирование REG.RU → api.primcom.ru. Дополнительно полезны приоритет прямого API для калькулятора и понятное сообщение на русском при таймауте. В этой проверке код и конфигурация сервера не изменялись. Доступ к серверному публикатору и его обновление отдельно не проверены; совпадение публичных файлов не доказывает настройку автопубликации.
