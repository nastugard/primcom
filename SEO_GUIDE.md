Суммы, найденные только у посредников (таможенный сбор, пороги льготы гибридов), в ответы не включены.
- Поддержка: при изменении правил ввоза обновить `seo/tag-cloud.json` и шаблоны `scripts/seo-tag-cloud.mjs`, затем `node scripts/build-tag-clouds.mjs` и генерацию каталога. Новые страницы каталога получают облако автоматически.

### Исправление измерения от 2026-09-13

Числа «45 длинных `title` и 46 длинных `description`», записанные ранее в этом разделе, были неверны.
Они получены подсчётом через `${#переменная}` в shell, который в этой среде считает **байты**, а не символы.
Кириллица в UTF-8 занимает 2 байта на символ, поэтому длины были завышены примерно вдвое:
заголовок главной — 132 байта, но 72 символа.

Корректное измерение новой сборки по 141 индексируемой странице:

| Показатель | Значение |
|---|---|
| `title` 30–60 символов | 131 |
| `title` длиннее 60 | 10, из них длиннее 70 — 3 |
| `description` 120–160 | 72 |
| `description` длиннее 160 | 1 (`rastamozhka-i-poshliny`, 170) |
| Дубли `title` среди индексируемых | 0 |
| Дубли `description` среди индексируемых | 0 |
| Страниц ровно с одним `H1` | 144 из 144 |
| Без `canonical` | только `404.html`, что корректно |

Вывод: массовая переработка мета-тегов не нужна. Исходная оценка аудита
«45 page(s) have title tags longer than 60 characters» требует независимой перепроверки,
поскольку могла быть получена тем же способом.

### Ложные срабатывания аудита — не чинить

- «Canonical mismatch» на главной: на production canonical корректный, `https://primcom.ru/`.
- «Отсутствует viewport»: Playwright не был установлен, мобильный рендер не состоялся.
  Тег на месте, `index.html:5`.
- Оценки LCP 2.73s и CLS 0.190 получены эвристиками без данных PageSpeed и CrUX.

- `llms.txt` не добавляем: Google его не учитывает, самостоятельного SEO-эффекта нет.

## 0.3 Защита от массовой деиндексации (2026-08-24)

- Синхронизация каталога больше не публикует результат, если у страны исчезли все активные модели или общее число активных моделей упало более чем вдвое.
- Причина: успешный ответ API с пустым списком объявлений формально валиден, но автоматически перевёл бы все модельные страницы в `noindex,follow` и убрал их из sitemap.
- Сборка в таком случае завершается ошибкой, работающие страницы не меняются, менеджер видит неуспешный SEO-статус в боте.
- Порог настраивается через `SEO_MIN_ACTIVE_RATIO` (по умолчанию `0.5`); намеренное сокращение каталога выполняется вручную с `SEO_ALLOW_CATALOG_SHRINK=1`.
- Ожидаемый эффект: исключён сценарий одномоментной потери 130 индексируемых URL из-за временного сбоя каталога.

## 1. Приоритет №1: чтобы сайт начал уверенно индексироваться по бренду

Если сайт не находится по запросу `Примком`, сначала решаем базу индексации.

### 1.1 Google

1. Добавить сайт в [Google Search Console](https://search.google.com/search-console/about).
2. Подтвердить права на домен ([официальная инструкция](https://support.google.com/webmasters/answer/9008080)).
3. Отправить sitemap: `https://primcom.ru/sitemap.xml` ([инструкция](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap)).
4. Проверить URL главной и ключевых страниц через URL Inspection и отправить на переобход.
5. Проверить отчет Indexing:
   - что в индексе;
   - что исключено и почему (canonical, noindex, soft 404 и т.д.).

### 1.2 Яндекс

1. Добавить сайт в [Яндекс Вебмастер](https://webmaster.yandex.ru/).
2. Подтвердить права на сайт ([официальная справка](https://yandex.ru/support/webmaster/ru/service/site-owner)).
3. Отправить `https://primcom.ru/sitemap.xml`.
4. Проверить раздел индексирования и ошибки обхода.
5. Задать региональность и проверить корректность контактных данных.

## 2. Технические SEO-практики (что уже внедрено и что поддерживать)

1. Уникальные `title` и `description` на ключевых страницах.
2. Canonical URL на страницах.
3. OpenGraph/Twitter meta для корректных превью.
4. Structured data:
   - `Organization`, `WebSite`, `AutoDealer/LocalBusiness`, `FAQPage` (с 26.10.2026 — на всех страницах с облаком тегов).
5. Актуальный `robots.txt` и `sitemap.xml`.
6. Юридические страницы (`privacy`, `consent`) выведены из индекса (`noindex,follow`) и исключены из sitemap, чтобы не размывать фокус индексации.

## 5. KPI, которые нужно отслеживать еженедельно

1. Индексация:
   - количество страниц в индексе Google/Яндекс;
   - доля исключенных URL и причины.
2. Брендовый спрос:
   - показы/клики по запросам `примком`, `primcom`.
3. Видимость по коммерческим запросам:
   - авто из китая под заказ;
   - авто из японии под заказ;
   - авто из кореи под заказ;
   - растаможка авто.
4. CTR в выдаче по приоритетным страницам.
5. Лиды с органики (заявки, звонки, сообщения).

## 6. Что проверять после каждой SEO-правки на сайте

1. URL отдает `200 OK`.
2. Нет случайного `noindex` на коммерческих страницах.
3. Canonical указывает на правильный URL.
4. Страница присутствует в sitemap (если должна индексироваться).
5. Структурированные данные валидны и без критических ошибок.
