# primkom-rf

Отдельная фронтовая копия для домена `примком.рф` (`xn--h1aefbjch.xn--p1ai`).

## Что реализовано (Этап A)

- Полная копия фронта вынесена в отдельную папку `primkom-rf/`.
- Дублируемые страницы помечены как:
  - `meta robots="noindex,follow"`
  - `rel="canonical"` на соответствующие URL `https://primcom.ru/...`
- Создана уникальная индексируемая страница:
  - `pages/o-kompanii-primkom.html`
  - self-canonical на `https://xn--h1aefbjch.xn--p1ai/pages/o-kompanii-primkom.html`
- Обновлен `sitemap.xml` (содержит только уникальную страницу).
- Обновлен `robots.txt` под домен `xn--h1aefbjch.xn--p1ai`.
- Добавлена сквозная перелинковка на `primcom.ru` в `header`, `footer` и на главной.

## Правило публикации

- Деплоить на `примком.рф` только содержимое этой папки.
- Не менять canonical/noindex для дублируемых страниц до появления уникального контента.
- В `sitemap.xml` добавлять только уникальные индексируемые страницы.

## Следующий этап (B)

- Добавить 3-5 уникальных контентных страниц (кейсы, FAQ+экспертка, чек-листы).
- Усилить блоки визуальных отличий (таймлайн компании, маршрут поставки, фильтруемые кейсы).
- Для каждой новой страницы:
  - `robots: index,follow`
  - self-canonical
  - включение в `sitemap.xml`
