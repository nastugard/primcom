# primkom-rf

Минимальный SEO-спутник для домена `примком.рф` (`xn--h1aefbjch.xn--p1ai`) в формате `1+контакты`.

## Текущая структура (боевой контракт)

- Главная: `/` (indexable)
- Контакты: `/pages/kontakty.html` (indexable)
- Все старые контентные URL: `301 -> /` (через Nginx)
- В `pages/` физически оставлен только `kontakty.html`
- Неиспользуемые для деплоя файлы перенесены в `useless/`

## SEO-правила

- Для `/` и `/pages/kontakty.html`:
  - `robots: index,follow`
  - self-canonical
- `sitemap.xml`: только 2 URL (главная + контакты)
- `robots.txt`: открыт для индексации, Host/Sitemap указывают на `xn--h1aefbjch.xn--p1ai`

## Редиректы

- Файл правил: `nginx/primkom-rf-redirects.conf`
- Подключается в `server`-блоке домена `xn--h1aefbjch.xn--p1ai`

## Контентная модель

- Главная: уникальный SEO-текст + 8-12 естественных переходов на `primcom.ru`
- Главная усилена визуальными секциями (бейджи, метрики, карточный маршрут сделки) без добавления новых URL
- Контакты: уникальный текст + 2-3 перехода на `primcom.ru`
- Формы заявок и сбор ПДн на спутнике не используются

## Рабочие документы

- Техническая документация: `TECH_DOCS.md`
- Отчет для заказчика: `CLIENT_STATUS.md`
- Чек-лист вебмастеров: `WEBMASTER_SETUP.md`
- Шаблон мониторинга: `SEO_MONITORING_TEMPLATE.md`

Эти файлы пополняются после выполнения задач.
