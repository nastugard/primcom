# TECH DOCS: primkom-rf

## Назначение

`primkom-rf` — фронтовый спутник бренда для перехвата и маршрутизации брендового/около-брендового трафика на `https://primcom.ru/` без дублирования основного сайта.

## URL-контракт

- `https://xn--h1aefbjch.xn--p1ai/` — indexable, self-canonical
- `https://xn--h1aefbjch.xn--p1ai/pages/kontakty.html` — indexable, self-canonical
- Legacy URL из старой структуры — постоянный `301` на `/`

## Redirect policy (Nginx)

- Конфиг: `nginx/primkom-rf-redirects.conf`
- Включает:
  - `/index.html -> /`
  - `/pages/ -> /`
  - список удаленных контентных страниц `-> /`

## SEO-политика

- `robots.txt` не блокирует ключевые URL
- `sitemap.xml` содержит только 2 индексируемые страницы
- На спутнике нет каталогов, автоген-карточек и дублирующих коммерческих разделов
- На спутнике не используется форма заявки (нет сбора ПДн)
