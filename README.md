# Примком: сайт и публикация каталога

Документация актуализирована 26.10.2026. Статический сайт `primcom.ru` работает на HTML, CSS и нативных ES-модулях без сборщика. Backend и Telegram-боты развёртываются отдельно.

## Состояние проекта

- Локальный каталог: 152 индексируемые генерируемые страницы, 163 URL в `sitemap.xml`. Включает подборки, разборы объявлений и руководство по аукционным листам.
- Главная: свежие подборки трёх стран объединены в одну секцию с вкладками Япония / Корея / Китай (`js/modules/latest-tabs.js`); загрузка карточек и API не менялись.
- Облако тегов «Полезно знать»: на 163 страницах по 10 тем с раскрывающимися ответами на поисковые вопросы и FAQPage JSON-LD (кроме `privacy`, `consent`, 404). Ручные ответы — `seo/tag-cloud.json`, для моделей и марок ответы считаются из реестра каталога. Подробности — [FRONTEND_DOCS.md](FRONTEND_DOCS.md) и [seo/README.md](seo/README.md).
- Общая форма передаёт контекст модели, подборки и успешного расчёта. Успех фиксируется только после HTTP OK и JSON `ok: true`; автоматической повторной отправки нет.
- Мобильная шапка до 860px: логотип, телефон и кнопка «Меню» в одной строке. Локальные версии CSS и `app.js`: `20261027-header-safari-1`; модули формы и аналитики: `20261018-organic-1`.
- Сохранённая проверка production от 18.10.2026 подтверждает публикацию органического релиза: 201/201 файлов совпали с пакетом, события открытия формы и расчёта получены Метрикой.
- 26.10.2026 все 202 публичных файла сверены с production по содержимому: хостинг совпадал с коммитом `a9e287f`, то есть мобильная шапка (`20261018-mobile-header-2`) опубликована. Релиз вкладок и облака тегов (`7340f52`) и исправление меню шапки в Safari (`46fd98d`) опубликованы: 27.10.2026 все 202 публичных файла production совпали с `46fd98d`. Обновление серверного публикатора (`deploy/seo-publisher-20261027-header-safari.zip`) не подтверждено.
- В проверке 18.10.2026 выявлены таймауты и HTTP 502 на маршруте REG.RU → API калькулятора; 26.10.2026 на живой главной японская подборка висела на «Загружаем свежие объявления». Реальная заявка менеджеру, повторная отправка sitemap и рост поисковых показателей не подтверждены.
- Известная ошибка расчёта: в `china_cars_backend/app/services/import_calculator/config.py` для машин до 3 лет нет ступени ЕТТ «42 300–84 500 € — 48%, не менее 7,5 €/см³»; диапазон до 169 000 € считается с минимумом 15 €/см³. Калькулятор завышает пошлину новых машин этой стоимости, а таблица на `pages/rastamozhka-i-poshliny.html` (строится из того же файла `scripts/build-customs-tables.py`) повторяет ошибку. Исправление затрагивает backend и требует его тестов и перезапуска — не выполнено.

## Локальная проверка

Из корня репозитория, Node.js 22 и Python 3:

```bash
node scripts/check-seo-pages.mjs
node scripts/build-tag-clouds.mjs --check
node scripts/test-organic-conversion.mjs
node scripts/test-seo-publisher.mjs
node scripts/test-sync-to-host.mjs
python3 scripts/build-customs-tables.py --check
git diff --check
```

Эти проверки пройдены 26.10.2026. Тест формы подменяет сеть; синхронизация проверяется на локальном транспорте. Они не отправляют заявки и не доказывают доступ к REG.RU. Универсальный `scripts/accuracy_report.mjs` в проекте отсутствует.

Предпросмотр: `python3 -m http.server 8123`, затем открыть `http://localhost:8123`. Генерацию HTML запускать отдельно: `node scripts/generate-seo-pages.mjs`; облако тегов на главной и `pages/*.html` обновляет `node scripts/build-tag-clouds.mjs` (данные — `seo/tag-cloud.json`); исходники — `seo/content-registry.json`, `seo/organic-content.json` и общие компоненты.

## Публикация и Git

На REG.RU загружается только публичная статика по инструкции в `DEPLOY_REGRU.md`. Git push сам по себе не подтверждает обновление сайта. Пакеты в `/deploy/`, реальные `.env` и `sync.env` исключены из Git; настройки серверов сохраняются отдельно.

22.10.2026 перед первым push история очищена с разрешения пользователя: ключ OpenAI, пароль PostgreSQL и старый токен Telegram заменены на заглушки во всех трёх локальных ветках. Переписаны 73 коммита; содержимое текущей версии проекта и локальных `.env` сохранено. Проверены все 4693 Git-объекта после очистки: три известных секрета и проверяемые шаблоны ключей/токенов не найдены. `git fsck` прошёл.

Коммит с обновлениями `3b9ae35` после очистки имеет хеш `aca4af2`; последующий коммит фиксирует результат очистки в документации. Старые хеши в отчёте об инциденте относятся к исходной истории. Проверенная резервная копия сохранена локально в `deploy/git-history-backup-2026-10-22_230643/`; она содержит исходные секреты и не должна загружаться на хостинг или в GitHub. Другие существующие клоны нужно синхронизировать с очищенной историей перед дальнейшей работой. Подробности — [отчёт об инциденте](SECURITY-OPENAI-2026-10-21.md).
