# Примком: сайт и публикация каталога

Документация актуализирована 22.10.2026. Статический сайт `primcom.ru` работает на HTML, CSS и нативных ES-модулях без сборщика. Backend и Telegram-боты развёртываются отдельно.

## Состояние проекта

- Локальный каталог: 152 индексируемые генерируемые страницы, 163 URL в `sitemap.xml`. Включает подборки, разборы объявлений и руководство по аукционным листам.
- Общая форма передаёт контекст модели, подборки и успешного расчёта. Успех фиксируется только после HTTP OK и JSON `ok: true`; автоматической повторной отправки нет.
- Мобильная шапка до 860px: логотип, телефон и кнопка «Меню» в одной строке. Локальные версии CSS и `app.js`: `20261018-mobile-header-2`; модули формы и аналитики: `20261018-organic-1`.
- Сохранённая проверка production от 18.10.2026 подтверждает публикацию органического релиза: 201/201 файлов совпали с пакетом, события открытия формы и расчёта получены Метрикой. Публикация последующего обновления мобильной шапки и серверного публикатора не подтверждена. Текущий production 22.10.2026 не проверялся.
- В той проверке выявлены таймауты и HTTP 502 на маршруте REG.RU → API калькулятора. Реальная заявка менеджеру, повторная отправка sitemap и рост поисковых показателей не подтверждены.

## Локальная проверка

Из корня репозитория, Node.js 22 и Python 3:

```bash
node scripts/check-seo-pages.mjs
node scripts/test-organic-conversion.mjs
node scripts/test-seo-publisher.mjs
node scripts/test-sync-to-host.mjs
python3 scripts/build-customs-tables.py --check
git diff --check
```

Эти проверки пройдены 22.10.2026. Тест формы подменяет сеть; синхронизация проверяется на локальном транспорте. Они не отправляют заявки и не доказывают доступ к REG.RU. Универсальный `scripts/accuracy_report.mjs` в проекте отсутствует.

Предпросмотр: `python3 -m http.server 8123`, затем открыть `http://localhost:8123`. Генерацию HTML запускать отдельно: `node scripts/generate-seo-pages.mjs`; исходники — `seo/content-registry.json`, `seo/organic-content.json` и общие компоненты.

## Публикация и Git

На REG.RU загружается только публичная статика по инструкции в `DEPLOY_REGRU.md`. Git push сам по себе не подтверждает обновление сайта. Пакеты в `/deploy/`, реальные `.env` и `sync.env` исключены из Git; настройки серверов сохраняются отдельно.

22.10.2026 у `origin` не обнаружено веток. Исторический коммит `5ad1ea3`, доступный из текущей ветки, содержит ключ OpenAI и непустой пароль PostgreSQL. Обычный первый push отправит эту историю. Перед отправкой требуется согласованная очистка истории; удаление секрета только из текущих файлов недостаточно. Значения секретов в документацию не включены.
